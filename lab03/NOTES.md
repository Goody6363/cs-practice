git restore - восстанавливает файлы из последнего коммита, а с помощью git restore --source=... - можно восстановить файлы с определенного коммита.
то есть если бы мы написали git restore то он бы вернул файлы в состояния последнего коммита, а с помощью git restore --source=... мы смоги бы вернуть файлы в состояния любого выбранного нами коммита
