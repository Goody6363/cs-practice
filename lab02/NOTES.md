Рабочая папка - место на компьютере, где находится проект и его файлы с которыми я работаю.
Индекс - список изменения которые я подготовил для следующеги коммита.
Коммит - сохраненная версия проекта в гит. Здесь пишется что было изменено, и при необходимости можно вернуться на эту версию.

Git - работает с кодом и историей изменений, а GitHub -просто хранит проект онлайн.
Git status - показывает состояние проекта
Git diff - показывает что изменилось в файлах, которые еще не добавлены в индекс.
Git diff --staged - показывает что изменилось в файлах, которые уже добавлены в индекс.

Ветка - это отдельный путь разработки проекта не затрагивающий Main.
При коммите в ветке сохраняется текущее сотояние проекта.
